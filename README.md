# Система технічної підтримки

Проєкт реалізований як модульний моноліт на Python.

## Модулі

- `auth` — вхід користувача та видача токена.
- `users` — реєстрація, перегляд користувачів, зміна ролей.
- `tickets` — створення тікетів, перегляд, зміна статусів.
- `messages` — повідомлення всередині тікета.
- `faq` — часті питання та відповіді.
- `admin` — статистика системи.

## Запуск

1. Встановити залежності:

```bash
pip install -r requirements.txt
```

2. Запустити застосунок:

```bash
uvicorn app.main:app --reload
```

3. Відкрити API-документацію:

```text
http://127.0.0.1:8000/docs
```
